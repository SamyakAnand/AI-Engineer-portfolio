# AI-Engineer-portfolio

Samyak Anand's portfolio website, built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and add the required server-side API configuration.
3. Start the development server with `npm run dev`.

## Production

- `npm run typecheck` checks TypeScript.
- `npm test` runs the unit tests.
- `npm run build` creates the production build.

The cinematic frame sequence, portfolio content, and public assets are included in this repository. Environment files and generated build output are excluded from version control.
