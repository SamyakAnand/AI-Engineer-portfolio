# SAM.exe chatbot reaction pack

Ten lightweight animated GIFs generated from the supplied transparent PNG reaction artwork.

| GIF | Chatbot state |
| --- | --- |
| `greeting.gif` | First welcome message |
| `thinking.gif` | Request is being processed |
| `typing.gif` | User is typing or the reply is streaming |
| `confident.gif` | Standard informative response |
| `celebrating.gif` | Milestones and positive outcomes |
| `confused.gif` | Clarification is needed |
| `gaming.gif` | Gaming-related responses |
| `sad.gif` | Empathetic responses |
| `error.gif` | Chat API or explicit failure |
| `idle.gif` | Closed or idle launcher |

Each file is a 4-frame, looping GIF with a subtle vertical bob. The chatbot uses Next.js `Image` with optimization disabled so the animation remains intact.
